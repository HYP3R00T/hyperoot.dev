## Variants

The badge primitive supports default, secondary, destructive, outline, ghost, and link treatments. Each variant uses the shared color tokens and compact typography from the Hyperoot interface system.

```tsx
<Badge variant="default">default</Badge>
<Badge variant="secondary">secondary</Badge>
<Badge variant="outline">outline</Badge>
```
